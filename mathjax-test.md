# MathJax Test Page

This page tests MathJax rendering with different types of equations.

## Inline Math

Here is some inline math: $f(x) = x^2 + 3x + 2$ and $\alpha = \beta + \gamma$.

## Display Math

Here is a display equation:

$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$

And another one:

$$E = mc^2$$

## Complex Equations

A more complex equation from the natural gradient paper:

$$g_{ij} = E_x\left(\frac{\partial f_\theta(x)}{\partial \theta^i}\frac{\partial f_\theta(x)}{\partial \theta^j}\right)$$

## Equation Arrays

$$\begin{align}
\frac{d\theta^i}{dt} &= -\frac{\partial L(\theta)}{\partial \theta^i}\\
\delta\theta^i &= -\eta\frac{\partial L(\theta)}{\partial \theta^i}
\end{align}$$

If you can see properly formatted mathematical equations above (instead of LaTeX source code), then MathJax is working correctly!
